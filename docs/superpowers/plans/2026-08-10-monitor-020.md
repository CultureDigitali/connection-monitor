# Connection Monitor 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver four colored tray indicators, one authoritative network snapshot, accurate units and session totals, stable quality, and a versioned updater-ready macOS release.

**Architecture:** `BandwidthMonitor` owns one measurement stream and session deltas. The backend publishes one immutable `ConnectionStats` snapshot to the tray and frontend. A focused `tray` module owns icon pixels and compact formatting; JavaScript owns only widget formatting.

**Tech Stack:** Rust 2021, Tauri 2.11, Tokio, sysinfo, vanilla JavaScript, Node test runner, GitHub Actions.

## Global Constraints

- Four tray items: green download, blue upload, dynamic quality, purple session data.
- No generic composite tray icon.
- One network measurement per second shared by every consumer.
- Rates are bits per second with Kbps/Mbps/Gbps units.
- Totals are session deltas with MB/GB/TB units.
- Version is `0.2.0`.
- No claim of Apple notarization without a Developer ID identity.
